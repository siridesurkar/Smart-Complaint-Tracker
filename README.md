Smart Complaint Tracker is a complaint management web application developed to simplify the process of registering and tracking complaints. Built with Python (Flask) and MySQL, the application enables users to submit complaints, receive a unique Complaint ID, and check the status of their complaint at any time through an easy-to-use interface.

Features
Submit complaints through an online form.
Generate a unique Complaint ID for each complaint.
Track complaint status using the Complaint ID.
Responsive and user-friendly interface.
MySQL database integration for storing complaint data.

Tech Stack: Python, Flask, MySQL, HTML, CSS, JavaScript
